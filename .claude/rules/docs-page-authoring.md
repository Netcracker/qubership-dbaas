Before writing or editing a README, a reference page, a how-to, or any other documentation page, load
`docs-page-authoring`, and `english-developer-style` with it. When a change adds, renames, or removes a user-settable
option, property, flag, or environment variable, an error a user can see, or a supported version, load it then too,
even where the task said nothing about docs, to decide whether the change owes the documentation an update.
