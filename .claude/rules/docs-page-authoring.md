Before writing or editing a README, a reference page, a how-to, or any other documentation page, load
`docs-page-authoring`, and `english-developer-style` with it. A change that adds or renames an option, a property, an
error a user can see, or a supported version owes the documentation an update: load it then too, even where the task
said nothing about docs.
