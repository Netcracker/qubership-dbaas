# DBaaS troubleshooting

Diagnose DBaaS Aggregator and DBaaS Operator incidents from support-ticket artifacts, exact error strings, platform
alerts, resource manifests, and source code. The skill is designed for offline assessment and does not require live
cluster access.

Install the package with APM:

```shell
apm install Netcracker/qubership-dbaas/agent-packages/troubleshoot-dbaas
```

Invoke the `troubleshoot-dbaas` skill when investigating a DBaaS incident.
